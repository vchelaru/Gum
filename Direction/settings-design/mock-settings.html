Rules in one place

  • Every page: title, one line saying where it's saved, then collapsible section bars. No flat lists.
  • Sections group by what the user is thinking about (Output, Locations, Namespaces), not by how the settings file is laid out.
  • One label column ~190px, so labels stay on one line. Long labels get shortened, with the full name in the hint.
  • Every row has a one-line hint. Hints say what it does or what it's relative to, never repeat the label.
  • Anything a user could get wrong about (file moves, experimental) is a callout, not a hint.
  • Values Gum works out itself are read-only with a chip naming the source.
