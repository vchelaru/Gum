# Project Tab

### Introduction

The Project Tab displays all Screens, Components, Behaviors, and Standard Elements in a project. Standard types are shown at the bottom of the tab as chips, and the rest are organized in folders.

<figure><img src="../.gitbook/assets/07_08 06 34.png" alt=""><figcaption><p>Project tab displaying a Gum project</p></figcaption></figure>

### Searching

The search bar can be used to find elements in your project by searching for their name. By default the following are searched:

* Screen Names
* Component Names
* Standard Element Names
* Behavior Names

<figure><img src="../.gitbook/assets/07_08 08 31.gif" alt=""><figcaption><p>Searching for "Button" displays all elements and behaviors with the word "button"</p></figcaption></figure>

Additionally, variable values can be searched by checking the **Search variables** checkbox. When checked, variable values are searched for the entered text.

<figure><img src="../.gitbook/assets/07_08 09 20.gif" alt=""><figcaption><p>Searching for variables checks all variable values</p></figcaption></figure>
