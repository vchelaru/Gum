# Creating a Project

Select **File** > **New Project** to open the New Project dialog. Gum also shows it the first time you run Gum. Hover the info icons in the dialog for an explanation of each option.

{% hint style="info" %}
Available in November 2026, or now if building Gum from source.
{% endhint %}

<figure><img src="../../.gitbook/assets/01_12 20 01.png" alt=""><figcaption><p>The New Project dialog</p></figcaption></figure>

To create a Gum project:

1. Enter a **Project name**, such as `MyGame`.
2. Set the **Location** to the folder that should contain the project. Gum creates a new folder named after the project inside it. The line under **Location** shows the exact folder.
3. Click **OK**. Gum creates the project and opens it.

## Creating a C# Project

Check **Create C# project** to also create a runnable game project with the Gum project inside it. Choose the game framework in **Platform**.

The **Command line** section shows the [`gumcli new`](../../cli/new.md) command that creates the same project.
